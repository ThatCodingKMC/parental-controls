# URL patterns blocked during work mode (on top of blocked domains).
# These are applied even if a domain is in the whitelist.

# Khan Academy: block the user-made games/programs section
# Personal projects use the same URL structure, so they are also blocked.
# Use ./grant.sh free 30 to give temporary access for project work.
khanacademy\.org/(computer-programming|cs)(/|$)

# ── Google's built-in games ──────────────────────────────────────────────────
# Searching "minesweeper", "snake", "solitaire", "pac-man", "tic tac toe" etc.
# gives a playable game right on google.com (which must stay whitelisted for
# school), so block the game SEARCHES, plus /fbx — the path Google serves
# those in-page games from — and the playable doodle archive.
google\.[a-z.]+/(search|complete/search)\?(.*&)?q=[^&]*(minesweeper|snake|solitaire|pac[^&a-z]{0,3}man|tic[^&a-z]{0,3}tac|dino|t[^&a-z]{0,3}rex|spinner|fidget|arcade|doodle|game)
google\.[a-z.]+/(fbx|logos/|doodles)
[?&]fbx=
